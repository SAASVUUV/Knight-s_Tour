1. Compilar com "ghc horse.hs -o ktp"
2. executa ktp
3. programa aguarda como input o nome de um arquivo texto formatado como especificado na descrição do trabalho
    ex: input.txt 
4. Output é dada no console, podendo ser salva em um arquivo usando as funcionalidades do console
    ./ktp > output.txt (LINUX)
    ktp > output.txt (WINDOWS)
